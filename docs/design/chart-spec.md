# APPI News 圖表設計規格（chart-spec）

> 站內所有**資料圖表／資訊圖**（SVG）的唯一風格準據。適用：文章內文的統計圖、對比圖、流程圖、狀態並列圖。
> 定案範本：`public/images/appi-news-392/2.svg`（四大央行利率政策方向）。
> 鐵則：**圖表一律原生 SVG 手繪／程式繪，禁止用生圖模型（gpt-image 等）畫圖表**——生成模型畫不準繁中字與數字，新聞站不能接受「漂亮但數據錯」。

## 1. 顏色（對齊 `src/styles/variables.css` design token 的 hex fallback）

| 用途 | 值 | 對應 token |
|---|---|---|
| 主文字（標題、數值、立場） | `#1e2030` | `--ink` |
| 次要文字（副標、說明、頁尾） | `#6e7276` | `--ink-3` |
| 品牌識別（徽章、標頭強調條） | `#1f3a5f` | `--appi-brand` |
| 資料強調／正向、行動方向 | `#a87515` | `--appi-accent`（金） |
| 中性狀態（不變、持平、無資料） | `#eef0f3` 底＋`#5e6070` 記號 | `--bg-soft`/`--ink-2` |
| 焦點欄底色 | `#eaf0f8` | `--bg-tint` |
| 分隔線、格線 | `#e8e9ed`（1px） | `--line-2` |
| 背景 | `#ffffff` | `--bg` |
| 危險／警示（僅醫療警訊等真警示） | `#a12a2a` | `--danger-text` |

規則：
- **文字永遠用 ink 階**，不穿資料色（禁全紅立場字）；顏色由色塊／圖形記號承載。
- 資料狀態**不得只靠顏色區分**：一律搭配形狀（箭頭方向、圖示）或直接文字標籤雙編碼。
- 多序列（≥2 條線/組長條）配色先跑 dataviz 驗證（CVD 分離）再用；超過 4 序列改拆圖。
- 危險紅只給真警示（症狀警訊、風險上升），不當一般序列色。

## 2. 字體與字級（SVG 內用 px；不受站上 CSS 守門管，但階梯對齊）

字族一律：`'Noto Sans TC','PingFang TC','Microsoft JhengHei','Noto Sans CJK TC','Heiti TC',sans-serif`

| 元素 | 字級 | 字重 |
|---|---|---|
| 圖表標題 | 26px | 700 |
| 副標（一句話讀圖） | 15px | 400 |
| 欄位／序列名稱 | 20px | 700 |
| 立場詞／關鍵值 | 22px | 700 |
| 說明列 | 14px | 400 |
| 頁尾（製圖署名、資料時點） | 13px | 400 |

畫布基準 960×600（3:2 附近皆可；長流程圖可加高）。文章頁顯示寬約 680px，**最小字 13px** 縮放後仍可讀，不得更小。

## 3. 版面解剖（由上而下）

1. **標題列**：左側 4×28 金色圓角豎條（`#a87515`）＋左對齊標題；下一行副標用一句話講「這張圖要你看懂什麼」。**標題不置中、不畫底線。**
2. **主體**：欄位間用 1px `#e8e9ed` 細分隔線，**不畫外框箱／卡片描邊**。留白寧多勿擠。
3. **焦點標示**（選用）：與本文主旨最相關的一欄，鋪 `#eaf0f8` 圓角底＋頂部 3px 金條；一張圖最多一個焦點。
4. **頁尾**：1px 分隔線；左「製圖：APPI News」、右「資料時點／資料來源」（皆 13px `#6e7276`）。**資料來源照文章實據寫，不可杜撰。**

## 4. 圖形記號

- 方向箭頭：圓形底（r=30）＋4.5px 白色圓頭筆畫箭頭；向上=強化/上升（金底）、斜上=漸進（金底）、水平=持平（中性底灰箭）、向下=下降（依語境金或中性）。
- 長條圖：直角端貼基線、頂端 4px 圓角、條間留 2px 以上空隙；數值選擇性直標（關鍵條才標，不逐條全標）。
- 折線：2px 線寬、資料點 ≥8px、僅端點與轉折直標。
- 流程圖：節點圓角矩形（rx=12）、連線 2px `#6e7276` 箭頭，層級以字級與品牌藍徽章區分。

## 5. 硬性禁止

- ❌ 生圖模型（gpt-image / dall-e / flux）產「圖表、含數字或文字的資訊圖」。
- ❌ 任何浮水印、外站網址字樣（歷史事故：`dreamer868.com` 殘留）。
- ❌ 全紅／全彩立場文字；文字穿序列色。
- ❌ 雙 Y 軸；序列超過 4 還硬塞同圖。
- ❌ 數據沒有文章內文或引用來源支撐（圖上的每個數字都要能在文中找到）。
- ❌ 置中大標＋底線、四欄各自框箱的舊模版。

## 6. 交付前自檢

1. 用 chromium headless 截圖檢視：字沒溢框、行沒重疊、縮到 680px 寬仍可讀。
2. 數字逐一對回文章內文。
3. 移除任何 `<text>` 殘留的模版字樣；`role="img"` ＋ `aria-label` 描述圖意。
