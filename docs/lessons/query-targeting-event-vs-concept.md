# 排名很好卻幾乎沒曝光：標題瞄準了「只活一週的專有名詞」

> 摘要：tech 93 篇進索引、多在 pos 4~10（第一頁），每篇卻只有 13.8 曝光——因為主標瞄準 `figure 03 bmw`、`fable 5` 這種事件字，90 天各只有 2~11 次曝光；同期唯一一篇概念解釋文拿到 177 曝光，差 16 倍 ｜ 範圍：SEO / 選題與下標 ｜ 狀態：gate 已上線（tech-radar 步驟 3.5＋newsroom 標題鐵則）｜ 日期：2026-07-29

對應 SOT：選題 gate `.claude/skills/tech-radar/SKILL.md` 步驟 3.5；下標鐵則 `.claude/skills/newsroom/SKILL.md` 步驟三開頭；稽核工具 `scripts/gsc-audit.mjs`。

## 問題（症狀）

站長的觀察是「搜熱門新聞時我們不在第一頁」。拉 GSC 90 天（2026-04-27~07-26）逐篇比對後，真正的數字和這個直覺不一樣：

**tech 分類根本不是排名輸，是排得上但沒人搜。** 112 篇裡 93 篇有曝光，位置大多在 pos 4~10：

```
i 177 c 1 pos  9.0   Passkey 通行密鑰是什麼：無密碼登入的運作原理與台灣導入現況
i 114 c 7 pos  7.4   人形機器人走進產線：Figure 03 量產達每小時一台⋯
i  97 c 3 pos  5.8   SK 海力士砸 19 兆韓元蓋封裝廠⋯
i  52 c 0 pos 10.8   Claude Fable 5 開出「Mythos 級」新層級⋯
```

但這些文章實際吃到的查詢字，90 天累計只有個位數到十幾次：

```
i 11 pos 5.6  figure 03 bmw
i  6 pos 9.0  claude npo
i  3 pos 9.7  fable 5
i  2 pos 8.0  work iq
i  2 pos 5.0  mythos 級
```

同一批資料裡，**有長期需求的概念字反而排不上**：`passkey 原理` pos 27.7、`asic` pos 44.5、`ai asic` pos 72.5。

也就是說：**排得上的都是沒量的字，有量的字排不上。** 全 tech 每篇平均 13.8 曝光，是七個分類裡倒數第二（僅高於 finance 的 6.2）。

## 原因（根因）

**根因一：可贏性 gate 管的是「選題」，管不到「下標瞄準哪個字」。**

`tech-radar` 步驟 3 的四項 gate（對口或在地／非純事件新聞／有 evergreen 角度／賽道未被壟斷）在**題材層**是有效的，但一個題材可以完全通過這四項，然後被下成一個純專有名詞的標題。〈SK 海力士砸 19 兆韓元蓋封裝廠、再綁台積電做 HBM4〉題材確實有 evergreen 解讀（先進封裝的戰略位移），但標題只讓它吃得到 `sk 海力士` 這種事件字。**gate 過了，曝光還是拿不到。**

**根因二：事件字的需求曲線在事件結束當週就歸零，且不複利。**
`figure 03 bmw` 這類字只在新聞週期內存在。排第 5 名沒有意義，因為分母本身趨近於零。而概念字（`人形機器人 產線`、`passkey 原理`）的需求是常態存在的，每篇文都在往同一個字累積權重。

**根因三：站上自己就有反證，但沒人把它讀成模式。**
tech 曝光第一名是〈Passkey 通行密鑰**是什麼**：無密碼登入的**運作原理**與台灣導入現況〉，177 曝光——它是全類唯一一篇「是什麼＋怎麼運作」的概念解釋文，其餘都是事件報導。**概念題 177 vs 事件題 11，差 16 倍**，樣本就在手上，只是沒被當成訊號。

**附帶釐清：熱門新聞第一頁本來就不是 SEO 能拿的。** Top Stories 版位吃的是發布者權威×發稿速度。實測搜 `日圓貶值163`、`達卡青奧桌球選拔`、`超加工食品NOVA分類`、`髖關節痛看哪一科`，本站一個都沒出現，第一頁是聯合／經濟日報／自由體育／康健／Heho。對手在事發五分鐘內發稿、域名有數十年歷史，這條沒有「優化一下就上去」的版本。把它當 KPI 會持續消耗產能且永不回報。

## 解法（怎麼修 + 現在怎麼維持）

**在下標端加第五項 gate（`tech-radar` 步驟 3.5）**，候選必填 `targetQuery`，三個檢查全過才留：

1. `targetQuery` **不得只由專有名詞組成**（產品名／公司名／型號／版本號）。要是概念詞或問題。
2. **三個月測試**：「三個月後還有人搜這個字嗎？」答不出「會」就重擬。
3. **主標必須含 `targetQuery` 的核心詞**。事件可以進副標或第一段當引子，主標不行。

改寫示範（同一題材、同一批素材，只換瞄準點）：

| 事件型標題 | 概念/問題型 | targetQuery |
|---|---|---|
| Figure 03 量產達每小時一台、BMW 組裝逾 3 萬輛 | 人形機器人真的能上產線了嗎？現在做得到與做不到的事 | `人形機器人 產線` |
| Claude Fable 5 開出「Mythos 級」新層級 | AI 模型分層怎麼看？選型時真正該比的三件事 | `ai 模型 選型` |
| SK 海力士砸 19 兆韓元蓋封裝廠綁台積電做 HBM4 | HBM4 為什麼把戰場推到封裝？ | `hbm4 先進封裝` |

**同一條鐵則寫進 `newsroom/SKILL.md` 步驟三開頭**，因為五條產線的下標都經過它，只加在雷達端蓋不到 `/admin`、article-draft 等其他入口。

**熱門事件不是不能碰**，但只在本站真有權威的窄領域（AI×健康、醫材法規、健康資料治理）碰，且一律改成概念形狀。

## 怎麼避免重犯 / 相關

- **判斷一個分類健不健康，不能只看平均排名，要看「每篇曝光」。** pos 4~10 配 13.8 曝光/篇，代表瞄準錯字而非內容差；這兩種病灶的處方完全相反（前者改下標，後者改內容深度），看錯會白做。
- **選題 gate 與下標 gate 是兩件事**，題材過關不等於標題吃得到字。新增任何產線時兩個都要接。
- **有反證就在站內資料裡**：新開一條產線或懷疑成效時，先跑 `node scripts/gsc-audit.mjs`＋逐篇 page 維度，找站上表現最好的那篇，問「它和其他篇差在哪」，通常模式就在裡面。
- **別把「熱門新聞排第一頁」當目標**：那是 Top Stories 的權威×速度賽道，不是 SEO 賽道。相關脈絡見 [`google-news-surfaces-and-cover-image.md`](./google-news-surfaces-and-cover-image.md)（Google News 已改自動抓取，站上基建才是槓桿）。
