# 標籤與用語整頓：碎標籤、同義合併、以及「中國用語不能盲目取代」

> 摘要：全站 1886 個標籤有 86% 只用過一次（碎標籤），真正該處理的是把高價值主題的「同義／英文縮寫」標籤收斂到單一 canonical，別讓 topic 集群與 tag 頁被同義詞稀釋；掃中國用語**一律 context-aware 逐一看上下文**，全域 sed 取代會改錯（代碼＝健保碼、用戶＝電信用戶、激活＝ML/刺激活動、網絡＝中醫/抽象網絡，皆合法）。｜ 範圍：內容/SEO ｜ 狀態：已解決（首輪合併）｜ 日期：2026-07-13

## 問題（症狀）

- **標籤碎裂**：494 篇文章共 1886 個不重複標籤，其中 1626 個（86%）只出現一次。碎標籤既無法形成集群、對 SEO/導覽也幾乎無貢獻。
- **同義標籤稀釋**：同一概念被多個標籤瓜分，尤其「英文縮寫 vs 中文」與「近義詞」：`TSMC`／`台積電`、`FinTech`／`金融科技`、`CVC`／`企業創投`、`TFDA`／`食藥署`、`半導體供應鏈`／`台灣半導體供應鏈`。同義分裂會讓 tag 頁與 topic 集群各自只收到一半文章。
- **中國用語疑慮**：擔心站上混入中國用語（軟件/視頻/芯片…）。

## 原因（根因）

- 標籤沒有**受控詞彙**：每篇文章（含自動產文）自由發明標籤，長期累積成碎片。
- 中國用語其實極少：全站是台灣作者/台灣用語產出，`芯片/軟件/智能/視頻/服務器/網絡(電腦義)` 幾乎 0 命中，且**無任何簡體字外洩**。真正的錯只有零星幾個（`存儲`、`美聯儲`）。而多數「看起來像中國用語」的詞在上下文其實合法（見下）。

## 解法（怎麼修 + 現在怎麼維持）

- **同義合併（首輪，高信心）**：把英文縮寫／同義詞收斂到中文 canonical，並在 frontmatter `tags` 去重：
  - `TSMC → 台積電`、`FinTech → 金融科技`、`CVC → 企業創投`、`TFDA → 食藥署`。
  - 用 node 腳本只改 `tags:` 這一行、保序去重（別動正文），共改 11 檔。
- **中國用語：context-aware 逐一審，不可盲目取代**。做法＝「候選詞 `grep` → 逐一看上下文 → 只改真錯」。本輪真正修掉的只有兩個：
  - `存儲 → 儲存`（appi-news-195「資料存儲地點」）。
  - `美聯儲 → 聯準會`（post-717/718，且同篇本來就混用 `聯準會`，統一之）。
  - **合法、不可改的假陽性**（血淚重點）：`代碼`＝健保代碼/銀行分行代碼；`用戶`＝電信用戶（吃到飽搶用戶）；`激活`＝ML 激活參數，或根本是「刺激｜活動」被切錯；`網絡`＝中醫功能網絡/氣血網絡、社區/照護網絡、抽象模型網絡；`音頻`＝台灣通用的音訊/音頻品牌；`短信`＝18 世紀史料裡的「一封短信（短的信件）」非簡訊。這些若被全域 sed 取代都會改錯。

## 怎麼避免重犯 / 相關

- **標籤治理**：新文章（含 newsroom／自動產文）應**從既有高頻標籤挑**，別自創同義詞；發現同義標籤即合併到 canonical。碎標籤（只用一次）多為長尾、可容忍，重點是**別讓高價值主題被同義詞瓜分**——那會直接稀釋 topic 集群（見 topic 用法）與 tag 頁。
- **掃中國用語的正確流程**：`grep` 候選詞 → **逐一看上下文** → 只改真錯；並順手掃**簡體字外洩**（`grep 这|说|软件|数据|网络…`）。**永遠不要**對 `代碼/用戶/激活/網絡/音頻` 這類「多義、上下文合法」的詞做全域取代。判準＝「這個詞在**這一句**是不是真的中國用語？」
- 相關鐵則：內容紀律（繁中台灣用語）見 `CLAUDE.md` §內容紀律；標籤餵 keywords/RSS/llms 見 `src/content.config.ts`。
