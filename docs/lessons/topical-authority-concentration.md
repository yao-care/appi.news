# 主題權威靠「收斂」賺，不是靠「多產」堆：別再跑平行的商品科技產線

> 摘要：512 篇／7 分類卡在排名 18、每週僅 162 訪客，科技作者 190 篇多是紅海商品新聞、稀釋站層級主題權威；解法是把作者收攏回打得贏的窄利基（AI×健康），並把選題從「獵熱度」改成「獵可贏性」 ｜ 範圍：SEO / 內容策略 / 自動化選題 ｜ 狀態：已解決（第一批 2026-07-14 上線） ｜ 日期：2026-07-14

## 問題（症狀）

站台效能已封頂（desktop 100 / mobile 90+ / TBT 0 / CLS 0），內容供給極充沛（512 篇、7 分類、每日自動產線），但實際讀者只有每週 ~162 人、文章總瀏覽 ~176 次；GSC 顯示 234 頁進索引、1744 曝光、**平均排名 18（第 2 頁死區）**、CTR 1.7%。唯一有動能的是健康分類（+186% WoW、真正進搜尋）。

科技作者張饒輝（=站長）掛名 190 篇、全站第二多，且有真頭銜（理事長／技術長／FHIR），但科技類排名 18、輸給只有一半篇數的健康。其中 152 篇是每日商品科技新聞（模型發布、募資、台積電漲價…），只有 ~38 篇是他真正對口的 AI×健康。

## 原因（根因）

1. **主題權威是「站層級」訊號，在單一利基內複利，不跨利基相加。** 一個站同時打科技＋健康＋國際＋財經＋運動＋生活＋焦點、512 篇自動量產，在 Google 眼裡＝低權威泛用站。排名 18 全線一致，正是「有被索引、但不被信任為任何領域權威」的簽名。
2. **有具名作者 + 高產量 ≠ 權威。** 權威是**站外賺來**的（名字被搜尋、被外站引用、Google 認得的實體），不是作者頁自我宣告頭銜就有。張饒輝的可信度真實，但長在 AI×醫療資訊/FHIR 這個窄利基與 weiqi.kids/yao.care 圈，**不在「gemini 3.5 pro」「台積電」的 SERP 上**。把有頭銜的人丟去寫他不對口、又被 iThome/科技新報/官方 blog 壟斷的紅海商品新聞，掛名是真的、內容不在他的車道。
3. **選題雷達獵「熱度」＝結構性撈紅海。** tech-radar 掃 OpenAI/Google blog、HN、arXiv、台積電，這些「熱」正好等於「全世界都在寫、被巨頭壟斷、上線即過期」。優化了錯的變數（熱度 supply-driven），該優化的是可贏性（demand + 車道 driven），兩者幾乎相反。
4. **內容多 ≠ 好；散 > 集中會傷排名。** 512 篇散在 7 分類 < 少數利基的深叢集。健康之所以是唯一贏家，正因它的內容密度意外越過門檻。

## 解法（怎麼修 + 現在怎麼維持）

收斂，不是再多產。第一批（2026-07-14，PR merge `0d67725`）：

- **桶 B｜剪枝**：刪 94 篇未上線的商品科技新聞排程存量（皆 `status:scheduled` 未上線，零成本止血）。
- **桶 C｜改署名**：58 篇已上線商品新聞 `author` 由 lightman 改 `appi-editorial`（非破壞、URL 不變、不 deindex），清乾淨作者頁 E-E-A-T。
- **桶 A｜收攏支柱**：新增專欄《AI 醫療現場》(ownerAuthor lightman) ＋ 3 主題叢集（醫療 AI 的信任與落地／數位健康與高齡照護／AI 醫材法規與健康資料治理），把 35 篇 AI×健康注入 `column` + `topics`（排除 3 篇關鍵字誤中的假陽性）。
- **內鏈加厚（系統性）**：`relatedArticles()` 原只吃 category/subcategory/tags，**加權同 `column`（+3）與 shared `topics`（每個 +3）**，讓全站文章底「延伸閱讀」優先導向同一權威叢集的姊妹文，而非撈到不相干同類新聞。（`src/utils/content.ts`）
- **源頭止血**：`tech-radar` 與 `weekly-report` 選題改「獵可贏性」——主獵場重指 AI×數位健康、GSC 站內需求當主訊號、加**可贏性 gate**（①對口或強台灣角度 ②非純事件新聞 ③有 evergreen 解讀角度 ④賽道未被巨頭壟斷，四項全過才發）。

## 怎麼避免重犯 / 相關

- **別再重開平行的「科技」商品產線。** 雷達要服務對口車道（AI×健康）＋健康引擎，不是跑一條追每日科技新聞的紅海線。新站/新選題一律過可贏性四項 gate（正本在 `.claude/skills/tech-radar/SKILL.md` 步驟 3、`weekly-report/SKILL.md` 步驟 3）。
- **判權威看站外訊號**（名字搜尋、被外站引用、Knowledge Panel），不是站內作者頁宣告頭銜。要讓 Google 認得一個作者是實體，是另一條較慢的 E-E-A-T 工程。
- **第二支柱要挑「你有可信度 + 打得贏」的**，不是挑產量多的。半導體看似有量（且已有主題檔），但非作者車道、又是 DigiTimes/工商/財訊 的重量級地盤，不做支柱。
- **內容多不是護城河，集中才是。** 擴新分類/新產線前先問：這是本站能贏的利基，還是又開一條稀釋權威的紅海戰線？
